phase-9: implement corporate_registry batch adapter (8 sub-sources)

New composite adapter covering company registries in six jurisdictions. Every
endpoint and rate limit was verified against official documentation; where no
free documented search API exists, the sub-source is implemented as an
auditable skip with its documented reason instead of an invented endpoint.

Supported sub-sources:
- companies-house (UK): api.company-information.service.gov.uk/search/companies,
  HTTP Basic with the API key as username, free key, 600 requests / 5 minutes
- nzbn (NZ): api.business.govt.nz/gateway/nzbn/v5/entities, header
  Ocp-Apim-Subscription-Key, free; the official rate limit is not published, so
  RATE_LIMITS.md records it as not published rather than inventing a number
- kvk-opendata (NL): opendata.kvk.nl HVDS, no auth, number-keyed only,
  1 request / minute / IP
- recherche-entreprises (FR): recherche-entreprises.api.gouv.fr, no auth, the
  official DINUM API that surfaces RNE data, 7 requests / second / IP
- kvk-zoeken (NL): api.kvk.nl/api/v2/zoeken, header apikey; this is a paid
  subscription that excludes private use, so it is skipped unless KVK_API_KEY
  is set and its skip reason says why

Unsupported sub-sources, reported as skips with documented reasons:
- inpi-rne (France): INPI publishes no free search API, bulk SFTP only
- asic (Australia): no public JSON API, web-only, DSP applications closed
  until 2027
- cipc (South Africa): no API, web-only enterprise search
